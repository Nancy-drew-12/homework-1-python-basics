# homework-1-python-basics

Многоуровневая банковская система, разрабатываемая поэтапно (7 дней) в рамках курса.

## Цель проекта

Отработать ключевые концепции ООП на Python:
- инкапсуляция
- наследование
- полиморфизм
- абстракция
- SOLID-принципы

Проект включает модели счетов, систему транзакций, аудит, отчётность и элементы безопасности.
Все данные хранятся в памяти приложения, без подключения к базе данных.

## Структура проекта

- `src/` - исходный код (модели, исключения, логика)
- `tests/` - тесты и демонстрации работы кода
- `docs/` - документация и описания алгоритмов
- `requirements.txt` - зависимости проекта

## Принятые решения

- PremiumAccount: фиксированная комиссия списывается при каждом снятии вместе с суммой; лимит овердрафта проверяется с учётом комиссии.
- Проценты на SavingsAccount начисляются только на активном счёте.
- объекты счетов наружу из Bank не выдаются, денежные операции проходят только через методы банка и подчиняются ночному запрету. Счёт, созданный напрямую в обход банка, этой защите не подчиняется (в Python нельзя полностью закрыть доступ к объекту);
- стоимость счёта (total_value) включает портфель инвестиционного счёта, закрыть можно только счёт с нулевой стоимостью, аналитика и рейтинг считают по полной стоимости.
  - `ReportBuilder` (`src/report_builder.py`): отчёты по клиенту, по банку и по рискам;
    вывод в текст (`to_text`), JSON (`export_to_json`), CSV (`export_to_csv`)
  - графики matplotlib (`save_charts`): круговая диаграмма долей счетов, столбчатая по клиентам,
    график движения баланса, операции по уровням риска
  - банк ведёт журнал движения денег (`Bank.get_ledger`), по нему строится график баланса
  - тест: `python tests/test_reports.py`, файлы сохраняются в `output/reports`
